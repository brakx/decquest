DEKQUEST APP PLAN
Last updated for Alpha 0.15.1

PROJECT GOAL
Draft and evolve a four-hero party from Magic-style cards, fight through 20 floors, use portals and save rooms, and defeat an evil Planeswalker.

STABLE OR COMPLETED
- Browser-based deployment through GitHub/Cloudflare.
- Mobile-responsive interface.
- ASCII welcome screen.
- Initiative and turn progression.
- Universal Party/Enemy target selection.
- Temporary allies from Reanimate-style effects.
- Autosave foundation and XML save concept.
- Difficulty and mana-value budget controls.
- Standard, Pauper, Legacy, and Vintage pool-selection UI.
- Keyword Test Draft.
- Boss-only exile warning concept.

ALPHA 0.15.1 CURRENT TEST FOCUS
- Restore keyword behavior after Alpha 0.15 regressions.
- Flying and Reach target legality.
- Deathtouch as lethal after positive damage.
- Double Strike as two separate damage events.
- Lifelink healing per damage event.
- Vigilance and Haste.
- Hexproof and Protection target legality.
- Indestructible tracks damage but survives lethal damage and Deathtouch.
- Trample keeps an explicit combat context.
- Trample spillover uses the original target group.
- Trample excludes original, defeated, and exiled targets.
- Trample automatically discards excess if no valid target remains.
- Boss-only exile bypasses Indestructible.

BALANCE DEFAULTS
Base budget = total permanent hero levels.
Optional room modifier = current room number.
Easy bonus = 0.
Normal bonus = random 1 to 2.
Hard bonus = random 2 to 3.
These values remain editable in Developer / Balance Testing.

VERSION RULE
Every build must update the browser title, visible title, debug version, README, save schema, autosave key, and asset cache keys.
