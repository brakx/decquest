# DekQuest Alpha 0.12

- Difficulty selection: Easy, Normal, Hard
- Normal adds +1 to enemy power and health
- Hard adds +2 to regular enemies and additional boss scaling
- Four-hero drafting flow
- Each hero chooses one of three random starter creatures
- Each hero is named after drafting
- Starter stats, colors, creature types, keywords, and mana abilities are applied
- Party review before entering the first room
- Universal targeting and temporary allies retained
- ASCII welcome screen retained
- Version 0.12 shown in browser title, visible title, debug bar, README, autosave key, and cache keys
