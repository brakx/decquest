# DekQuest Alpha 0.9

## Autosave

- Saves the current run to browser `localStorage`.
- Saves after starting a run, choosing a portal, completing a room, choosing a level reward and sticker, reaching a save point, restoring a boss checkpoint, hiding the page, and closing the page.
- Main menu shows **Continue Autosave** when saved data exists.
- **Clear Autosave** removes local saved data and starts a new run.
- Active combat is restored to the start of the current room rather than the middle of a turn.
- The debug bar displays the most recent autosave time.

## Version consistency

Browser title, visible title, debug indicator, README, save version, and cache-busting parameters are all set to Alpha 0.9.
